# Experiment record — fill before execution, append after execution

This is a template, not a completed registration. `UNSET` means not registered and blocks dependent execution. Never fill a field by inventing evidence.

## Claim boundary

Choose the accurate state: planned / implemented-unvalidated / running / failed-preserved / completed-descriptive / independently-accepted-for-this-scope. A passed unit check does not imply physical acceptance, calibration, generality or publication readiness. Every claim must identify its actual supporting artifacts.
