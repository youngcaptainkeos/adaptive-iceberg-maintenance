# Historical experiment registrations

These JSON files bind exact code, sources, output identities, gates and cutoffs. Their contents and filenames are preserved during the package reorganization. They are not reusable launch presets for the current source tree.

Useful families:

- `physical_study*`: physical cohorts and recovery registrations.
- `timing_headroom*`: the repeated development timing experiment.
- `terminal_followup*`: identity-bound completion and analysis orchestration.
- `*publication*`, `*snapshot*`: observer/model boundary proofs and preparation.
- `*continuation*`, `*probe*`: later diagnostics and submission-overhead work.

For a new study, create a new registration with current grouped source paths and hashes; do not edit one of these historical files. Follow the top-level package README for the current directory map and operating requirements.
